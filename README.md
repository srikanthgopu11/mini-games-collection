# 🎮 Mini Games Collection

A responsive web application featuring four interactive mini-games built with React. The project brings together engaging gameplay, reusable components, routing, and responsive user interface design.

## 🚀 Live Demo

Coming soon — the project will be deployed on Netlify.

## ✨ Features

- **Emoji Game:** Test your memory by interacting with emojis.
- **Rock-Paper-Scissors:** Play against the computer and see the result of each round.
- **Memory Matrix:** Challenge your memory by remembering highlighted patterns.
- **Card Flip Memory Game:** Match cards and improve your memory.
- **Responsive Design:** Designed to work across desktop, tablet, and mobile screens.
- **Interactive Gameplay:** Includes game instructions, score or result views, and replay options.
- **Reusable Components:** Built with React components and state management.
- **Navigation:** Move between the home page and individual games using React Router.

## 📂 Project Setup

### Prerequisites

- Node.js and npm installed on your computer.
- Git installed to clone the repository.

### Installation

1. Clone the repository:

   ```
   git clone https://github.com/srikanthgopu11/Mini-Games-Collection-of-Memory-Games-.git
   ```

2. Navigate to the project directory:

   ```
   cd Mini-Games-Collection-of-Memory-Games-
   ```

3. Install the dependencies:

   ```
   npm install
   ```

4. Start the development server:

   ```
   npm start
   ```

5. Open the local URL displayed in your terminal to explore the application.
